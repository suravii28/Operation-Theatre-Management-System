## Purpose

## Review steps

1. Confirm the applicable OTMS feature and the current implementation behavior.
2. Identify expected behavior and relevant user roles or operational constraints.
3. Record test inputs or an operational example, including edge cases.
4. Compare the observed behavior with the expected outcome when the feature is exercised.
5. Capture evidence, defects, and follow-up actions in the project's normal tracking workflow.
